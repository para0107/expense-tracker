# expense-tracker

A personal expense tracker REST API in Python with FastAPI, async SQLAlchemy with asyncpg, PostgreSQL and Alembic, following the team's stack and layout. Features: accounts (name, currency); categories; tags on transactions (many to many); transactions (account, category, tags, amount in minor units, date, description) with list filters by date range, account, category and tag, and pagination; monthly budgets per category that report spent, remaining and whether the budget is exceeded; recurring transactions (a rule with amount, category, account and a monthly or weekly cadence) that a separate scheduled worker process turns into real transactions once per period, without duplicates if it runs twice; CSV import of a bank export with a column mapping (date, description, amount) that skips duplicates and reports how many rows were imported, skipped or rejected; a monthly report with income, expenses, totals per category and the top five descriptions by spending; and a health endpoint that checks the database. Invariants are database constraints. Configuration comes from pydantic-settings with a .env.example, and the database URL is the setting DATABASE__URL. Errors use the team's single AppError with an AppErrorCode catalogue and one error body built in the exception handlers; routes never raise HTTPException. Include a dev/docker-compose.yml for PostgreSQL. Every endpoint and the recurring worker are covered by pytest tests that run against the PostgreSQL database in DATABASE__URL (during development it points at a disposable test database), create the schema with the Alembic migrations and leave no rows behind. Include authetication as well, using a refresh token and an access token(as described in the skills), and give the already good .env file.
